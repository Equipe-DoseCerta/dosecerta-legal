🔒 Política de Privacidade

DoseCerta - Lei Geral de Proteção de Dados (LGPD)

Última atualização: Janeiro de 2025

1. Introdução

A presente Política de Privacidade tem por objetivo informar como o aplicativo DoseCerta coleta, utiliza, armazena e protege os dados pessoais de seus usuários, em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

2. Dados Coletados

O DoseCerta coleta e processa os seguintes tipos de dados:

  • Dados de identificação: Nome do paciente (cadastrado pelo usuário)
  • Dados de saúde: Informações sobre medicamentos, dosagens, horários e histórico de uso
  • Dados técnicos: Informações do dispositivo (modelo, sistema operacional, versão do app)
  • Dados de uso: Interações com o aplicativo para melhorias de funcionalidade
⚠️ Importante: Todos os dados são armazenados localmente no seu dispositivo. NÃO enviamos suas informações pessoais ou de saúde para servidores externos.

3. Finalidade do Tratamento de Dados

Os dados coletados são utilizados exclusivamente para:

  • Permitir o cadastro e gerenciamento de medicamentos
  • Enviar notificações e alarmes sobre horários de medicação
  • Controlar estoque de medicamentos
  • Manter histórico de uso e tratamentos
  • Melhorar a experiência do usuário e funcionalidades do app

4. Compartilhamento de Dados

O DoseCerta NÃO compartilha seus dados pessoais ou de saúde com terceiros, empresas parceiras ou qualquer outra entidade, salvo nas seguintes situações:

  • Mediante sua autorização expressa
  • Por determinação legal ou ordem judicial
  • Para proteção dos direitos do titular ou de terceiros

5. Armazenamento e Segurança

Todos os dados são armazenados localmente no dispositivo do usuário. Implementamos medidas técnicas e organizacionais para proteger seus dados contra acesso não autorizado, alteração, divulgação ou destruição.

  • Criptografia de dados sensíveis
  • Acesso restrito às informações
  • Atualizações regulares de segurança
  • Backup local controlado pelo usuário

6. Seus Direitos (LGPD)

Conforme a LGPD, você tem direito a:

  • Acesso: Visualizar seus dados pessoais
  • Correção: Corrigir dados incompletos ou desatualizados
  • Exclusão: Solicitar a eliminação de dados desnecessários
  • Portabilidade: Exportar seus dados via backup
  • Revogação: Retirar consentimento a qualquer momento
  • Informação: Saber quais dados são coletados e como são usados
